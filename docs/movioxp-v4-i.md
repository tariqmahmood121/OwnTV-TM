# MovioXP 4.0 I — Cinema Navigation

- Featured Movie Settings offers automatic rotation, four intervals, and a Trending-only mode. Settings and playback of the feature timer use local profile-scoped storage.
- Movie and series catalogues default to verified full-date newest-first ordering. Cinema badges display release years and known IMDb ratings.
- Cinema Discover and Series open category selectors that lead to the existing paged grids. Grid posters keep fixed dimensions and reserve room for the focused title’s details.
- Cinema Search offers Filter before Browse Titles. Focusing the Home feature controls returns Home to the absolute top.
