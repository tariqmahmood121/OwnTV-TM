# MovioXP 3.1.0-qa4

Android QA build, version code 100095.

- Home channel and sports shelves now use compact landscape cards that follow the Home size setting.
- Live TV artwork fits inside a 16:9 frame, with the full logo and image visible and a transparent backing when artwork is available.
- Channel names and available live and event metadata remain visible. TV focus uses the existing MovioXP highlight.

Device checks pending for Sport X artwork, Home row sizing, remote focus, touch layouts, and installing over QA3. See the [QA3 notes](movioxp-qa3.md) for existing Central compatibility limits.
