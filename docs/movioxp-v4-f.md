# MovioXP 4.0 F — Cinema Experience and Navigation Refinement

- Cinema Home uses OwnTV's edge-dissolve treatment. The Trending backdrop extends behind the first shelf and scrolls with Home.
- Cinema collection cards use a pink-to-magenta gradient, category-specific text, and a white focus outline. Collections opened from Home or Search use the paged catalogue with an anchored heading.
- Short Back dismisses the current level. Holding Back for two seconds and releasing returns to Home. The shell uses its existing playback-progress flush before stopping playback.
- The simulator uses a directional-pad layout when the remote is below the viewport. The emulator test checks short Back, the hold threshold, D-pad, OK, and focus in a scaled overlay.

Physical remote and unfolded foldable testing remain outstanding, including live catalogue content and playback progress across the full navigation path.
