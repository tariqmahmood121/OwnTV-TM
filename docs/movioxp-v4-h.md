# MovioXP 4.0 H — Cache-first Cinema Home

- Home restores a profile- and source-scoped pool of featured titles and checks existing catalogue caches before relying on network results.
- Featured images are decoded before they replace the current backdrop. Rotation keeps the current movie when the replacement fails.
- Missing artwork now leaves a compact status and retry control. Catalogue and artwork completion timings are recorded in debug builds.
- The release keeps the Cinema layout, category grids, Back behavior, and simulator controls.
